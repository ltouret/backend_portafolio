## What it is

A game with no JavaScript in the source. It's built with Eliom, OCaml's full-stack web framework: the server that sends the page and the game engine that runs in the browser are both OCaml, and the engine is compiled to JavaScript with js_of_ocaml. It was a 42 school project. You can [play it here](https://game.ltouret.dev).

## The game

Creatures called creets wander the screen. The river at the top makes them sick, and sick creets infect the healthy ones they touch. You drag sick creets down to the hospital to cure them. If you're too slow, some turn into variants you can't grab: a berserk one that grows until it bursts, or a mean one that shrinks and chases the nearest healthy creet. New creets keep arriving, everything keeps speeding up, and the game ends when nobody healthy is left.

## How it's built

- **No game library.** The engine is one file, `engine.eliom`. It moves each creet as a DOM element and handles collisions, infection, evolution and spawning.
- **Concurrency with Lwt.** The game loop and the mouse handling are cooperative threads. A drag is a race between "mouse moved" and "mouse released", and it is cancelled if the creet evolves while you're holding it.
- **Docker.** The whole toolchain lives in an image with OCaml 4.14, Eliom and js_of_ocaml. A second Compose file gives a dev mode that rebuilds when the source changes.

The live demo runs on my [home lab](/projects/home-lab/).
