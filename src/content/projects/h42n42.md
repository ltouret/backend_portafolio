## What it is

A 42 school project built with Eliom, OCaml's full-stack web framework. The server and the browser code are written in the same language. Eliom serves the page from an Ocsigen server, and the game engine is compiled to JavaScript with js_of_ocaml to run in the browser.

## The game

- Creatures called **creets** move around the screen at random.
- Touching the river makes them sick, and sick creets infect healthy ones on contact.
- You drag sick creets to the hospital to cure them.
- Over time, sick creets can turn into one of two variants that can't be cured:
  - **Berserk:** grows until it explodes.
  - **Mean:** shrinks and hunts down the nearest healthy creet.
- New creets keep spawning and the game speeds up. It ends when no healthy creet is left.

## How it's built

- `engine.eliom` is the client-side engine: movement, collisions, infection, the evolution of sick creets, and spawning.
- `h42n42.eliom` is the server side: routing and the HTML page.
- It runs in Docker with OCaml 4.14, Eliom and js_of_ocaml. A second Compose file gives a dev mode that rebuilds when the source changes.
